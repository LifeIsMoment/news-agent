# AI 세무·법률 / TAXiA·CLOA 자동 모니터링

매일 공개 자료를 수집해 **TAXiA·CLOA·XAIKOREA 관련 변화**와 **AI 세무·법률 규제 변화**를 GitHub 이슈 및 날짜별 Markdown 보고서로 발행합니다.

## 자동 실행

- 기본 실행: **매일 오전 7:00, Asia/Seoul** (`0 22 * * *` UTC)
- 누락 감시: **오전 7:20**에 그날 보고서가 없을 때만 재실행
- 수동 실행: `Actions → Daily AI Tax Legal TAXiA CLOA Monitor → Run workflow`
- 전달: 날짜별 GitHub 이슈 생성 또는 갱신
- 알림: 이슈를 `LifeIsMoment` 계정에 할당
- 보관: `reports/YYYY/MM/YYYY-MM-DD.md`와 원시 구조화 JSON
- 실패: 별도의 `monitor-failure` 이슈 생성

GitHub 예약 작업은 서비스 부하로 실제 시작이 지연되거나 드물게 누락될 수 있습니다. 그래서 07:20 보조 스케줄과 실패 이슈를 함께 사용합니다.

## TAXiA·CLOA 집중 모니터링

다음 명칭과 자산을 상시 확인합니다.

- `TAXiA`, `택시아`, `taxia-core`
- `CLOA 엔진`, `CLOA engine`
- `XAIKOREA`, `엑스에이아이코리아`
- `xaikorea/taxia` GitHub 저장소의 릴리스·커밋·이슈·PR·메타데이터
- PyPI `taxia-core` 릴리스
- Hugging Face `xaikorea0` 모델·데이터셋·Space
- TAXiA 공식 문서 페이지 변경
- 언론, 검색 색인, 외부 GitHub 언급
- 세무·회계·리걸테크 경쟁 서비스와 시장 변화

`CLOA` 및 `XAIKOREA`에는 동명·유사명 결과가 존재하므로, 세무·회계·TAXiA 문맥이 없는 개인비서·화장품 등의 결과는 자동 제외합니다.

## 세무·법률 모니터링 범위

대한민국을 우선하고 EU, 미국, 영국, 일본, 중국 및 국제기구를 보완합니다.

- 세무: 법인세, 부가가치세, 원천징수, 세액공제, 이전가격, 디지털·AI 서비스 과세, 국세행정
- AI 규제: 제공자·배포자 의무, 고위험 AI, 투명성, 안전·책임
- 개인정보: 학습데이터, 로그, 자동화된 결정, 국외이전, 보안
- 지식재산: 저작권, 특허, 상표, 학습데이터와 생성물
- 경쟁·플랫폼, 노동·채용, 금융·소비자, 사이버보안·제품책임
- 법령, 판결, 행정처분, 지침, 입법·행정예고, 의견수렴, 시행일

검색식은 [`config/sources.json`](config/sources.json)에서 관리합니다.

## 신뢰성 장치

- 매일 8시간 중첩 조회로 색인 지연 보완
- 180일 중복 제거 상태 보존
- 같은 날짜 재실행 시 기존 보고서와 병합
- 소스 하나의 장애가 전체 수집을 중단하지 않는 격리 구조
- 거의 모든 소스가 실패하면 워크플로를 실패 처리하고 경고 이슈 생성
- 보고서와 상태를 저장소에 커밋해 감사 추적 유지
- 07:20 watchdog으로 기본 예약 누락 확인

이 저장소는 현재 **공개 저장소**입니다. 자동 이슈와 보고서도 공개됩니다. 고객정보, 계약서, 내부 전략, 비공개 세무자료를 입력하지 마십시오.
